# Protocol compliance

Protocol-specific compliance workflows live in separate subdirectories:

- [MCP compliance](../library-ioa/compliance/mcp/README.md) — official npm conformance revisions and CI artifacts.
- [A2A compliance](../library-ioa/compliance/a2a/README.md) — deterministic MAS Lab fixture and official A2A TCK.

Install and run each workflow from its own directory. Generated results and
third-party TCK checkouts are ignored and must not be committed.
